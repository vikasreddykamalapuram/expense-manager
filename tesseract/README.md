# Self-hosted Tesseract assets

Generated by `scripts/sync-tesseract-assets.mjs` — **do not edit by hand**.

These are served from our own origin so that no executable JavaScript or
WASM is fetched from a third-party CDN into an origin that holds financial
data. On Android and iOS they are bundled into the app, so receipt OCR
works with no network at all.

Both LSTM cores are present because tesseract.js chooses the SIMD build
only when the browser supports it.

Total: 8.54 MB. Re-run the script after upgrading tesseract.js.
