# v3.2.0 — First Play Store release

**What's new**

- Real-time cross-device sync (Google or Microsoft sign-in). Edit on one device, watch it appear on another in ~2 seconds.
- Native Android app with biometric app-lock, PIN fallback, and screenshot protection.
- Local push notifications for bill reminders and daily add-expense nudge.
- Pull-to-refresh, swipe-to-delete, and haptic feedback throughout.
- Six-view analytics + monthly reports + financial health score.
- NSE stock portfolio with live prices (2,130+ stocks) and Geojit trade import.
- Bank statement PDF import with column-aware parsing.
- Deep linking: opening https://vikasreddykamalapuram.github.io/expense-manager/* launches the app directly.

Local-first, private-by-default, no ads, no subscription.
